# RTR-Align: Construction Safety VQA Annotation Refinement

This repository provides supplementary materials related to the annotation refinement process used in the RTR-Align study.

## 1. Overview

RTR-Align is a framework for construction safety violation recognition and localization based on rule-to-region alignment.

The study uses the ConstructionSite10k dataset with refined annotations to support more accurate violation recognition and spatial localization.

## 2. Annotation Refinement

The annotation refinement process includes three main aspects:

1. **Merged instances:** Separating multiple targets grouped within a single bounding box.
2. **Inaccurate boundaries:** Adjusting bounding boxes to better fit the target regions.
3. **Missing annotations:** Supplementing omitted targets based on safety rules and visual evidence.

## 3. Data Availability

The original dataset images are not redistributed. The availability of complete refined annotations is subject to the original dataset's licensing terms and any necessary permissions.
